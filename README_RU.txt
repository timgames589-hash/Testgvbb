SBA OVERLAY — проект Kotlin для PocketCode
============================================

Что есть в версии 0.2:
- отдельное Android-приложение;
- запрос системного разрешения «Поверх других приложений»;
- плавающая перетаскиваемая кнопка с медведем;
- меню поверх других приложений;
- «Эмоции» — ряд эмодзи, по тапу всплывает большая реакция над кнопкой на 1.5 сек;
- «Профиль» — поле для имени медведя, сохраняется на устройстве (SharedPreferences),
  при следующем открытии меню показывается приветствие с этим именем;
- остановка плавающей кнопки из главного окна.

ВАЖНО:
Это отдельное приложение. Оно не изменяет Super Bear Adventure и не читает/меняет её файлы.

СБОРКА ЧЕРЕЗ GITHUB ACTIONS (самый надёжный способ):
1. Создай пустой публичный репозиторий на github.com (с телефона — через браузер или приложение GitHub).
2. Загрузи туда все файлы из этого архива, сохранив структуру папок (включая .github/workflows/build-apk.yml).
3. Во вкладке Actions запусти workflow "Build APK" вручную (Run workflow) —
   либо он запустится сам при пуше в ветку main.
4. Через пару минут в разделе Actions → запуск → Artifacts появится sba-overlay-debug-apk.zip —
   скачай и распакуй, внутри будет app-debug.apk, готовый к установке.

Открытие:
1. Распакуй ZIP в отдельную папку.
2. В PocketCode создай/импортируй Android App project (Kotlin).
3. Если PocketCode предлагает импорт ZIP-проекта — выбери этот ZIP.
4. Собери APK через Build APK в Android-проекте.

Если импортёр PocketCode не принимает ZIP напрямую:
создай Android App (Activity) project и перенеси файлы/папки, сохраняя пути:
- app/src/main/AndroidManifest.xml
- app/src/main/java/com/timker/sbaoverlay/MainActivity.kt
- app/src/main/java/com/timker/sbaoverlay/OverlayService.kt
а также Gradle-файлы из корня и app/.

Требования:
- Android 6.0+ (minSdk 23)
- compileSdk 35
- Gradle Android plugin 8.7.3
- Kotlin plugin 2.0.21

Первый запуск:
1. Открой SBA Overlay.
2. Нажми «Разрешить показ поверх приложений».
3. В настройках Android включи разрешение для SBA Overlay.
4. Вернись в приложение и нажми «Запустить плавающую кнопку».
5. Нажми на медвежью кнопку, чтобы открыть меню.
6. Перетаскивай кнопку пальцем.

Если Android спросит разрешение на уведомления — разреши его, чтобы видеть статус сервиса.
